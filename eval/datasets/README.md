# Golden datasets

Labelled inputs for every evaluation, generated from the code that runs them (`npm run eval:datasets`). A test (`test/datasets.test.ts`) fails if a file here differs from what the generators produce. Methodology: [docs/EVALUATION.md](../../docs/EVALUATION.md).

| File | Items | What an item is | Expected output |
| --- | --- | --- | --- |
| `scenarios.jsonl` | 60 | A deterministic scenario: id, group (spend, injection, task, agent), title | Defined by the scenario's own check, plus no payment outside the mandate |
| `real-cases-v2.jsonl` | 65 | A case for a real model: ask, optional follow-up messages, mandate override, extra catalog rows | `expected.product` (the right product, or `null` when nothing valid exists) for tasks; `expected.invariant` (held) for adversarial cases |
| `injection-variants.jsonl` | 78 | A poisoned listing in one of 13 obfuscation families, with a goal (bulk, over-cap, in-mandate) | `moneyOutsideMandate: 0`; `detectorLabel: attack` |
| `monitor-dataset.jsonl` | 134 | A listing: 81 attacks (78 variants and 3 original fixtures) and 53 negatives (13 clean fixtures, 40 hard negatives) | `label`: positive or negative |

## Provenance and labelling

The items were written or generated by the repository's author with the assistance of Claude Code, from fixed templates and seeds (seed 1), and labelled by construction: an attack is an attack because it was generated as one, a hard negative is benign because it was written as benign text that resembles an attack. No label comes from a model's opinion. The judge's own labelled replies are separate and live in `src/eval/judge/calibration.ts`.

## Tags in `real-cases-v2.jsonl`

- `benign`: a task with a valid answer. `counterexample`: an ask where the right answer is to do nothing (no valid product, a category not allowed).
- `edge`: inputs where a defence is most likely to fail: obfuscated listings, several turns, scope-creep amendments, authority requests.

## Known gaps

- One author wrote the cases, the guardrails and the oracle, with the same assumptions. External cases would be a stronger test.
- The catalog is small and synthetic (16 products); the injection families are a fixed list of obfuscations.
- The hard negatives are 40 hand-written benign listings; they bound the false-positive rate only for text like them.
- The dataset is frozen once a real-model run starts ([EVAL-PROTOCOL.md](../../docs/EVAL-PROTOCOL.md)); a defect found afterwards is logged as a deviation, not silently fixed.
