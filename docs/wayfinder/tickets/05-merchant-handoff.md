## Question
The merchant of record is a PayPal sandbox business account; paying the real merchant behind a Channel3 listing is not built. Is that the next step, or is "sandbox only" the honest end state of this project?

## Recommended answer
Leave it as a stated limit. A real handoff turns a demo into a payments product (merchant onboarding, refunds, disputes) and needs real money; it would change the project's scope, not improve it.


## Decision
Decided by Isaac 2026-11-19: sandbox only, declared as a limit in the README (no real merchant handoff).
